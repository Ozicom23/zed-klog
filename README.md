# zed-klog

klog support in Zed.

[klog](https://klog.jotaen.net) is a plain-text file format for time tracking.
This extension adds syntax highlighting for `.klg` files.

## Installing as a dev extension

1. Make sure `rev` in [`extension.toml`](extension.toml) points to a commit that
   contains the grammar (see below).
2. In Zed, run `zed: install dev extension` and select this folder.

## Repository layout

- `extension.toml`: the extension manifest.
- `languages/klog/`: language config and the highlight query.
- `tree-sitter-klog/`: the tree-sitter grammar, written from the
  [klog specification](https://github.com/jotaen/klog/blob/main/Specification.md).
  - `grammar.js`: the grammar rules.
  - `src/scanner.c`: a small external scanner for line breaks and indentation.
    klog's indentation style is set per record by its first entry, which decides
    whether an indented line is a new entry or continues an entry summary.
  - `src/parser.c` and the rest of `src/`: generated by `tree-sitter generate`.
    These files are committed, because Zed compiles the parser from them.
  - `test/corpus/`: parser tests.

## Changing the grammar

```bash
cd tree-sitter-klog
npm install
npx tree-sitter generate
npx tree-sitter test
```

Then commit, including the regenerated `src/` files, and set `rev` in
`extension.toml` to the new commit so that Zed picks up the change. Zed only
rebuilds the grammar when you reinstall or rebuild the dev extension.

Highlighting only needs `languages/klog/highlights.scm`. Edits to it apply
after a rebuild, with no new commit needed.
